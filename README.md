# Lorensic Disasters

Lorensic Disasters is a Minecraft plugin that introduces natural disasters like tornados, hurricanes, lakebursts, tsunamis, flashfloods, and whirlpools. It features realistic water gravity systems, rain puddles, rain particles, water vapor particles, and realistic disaster effects. The plugin supports various intensities for each disaster, including EF1-5 for tornados, Category 1-5 for hurricanes, and different sizes for lakebursts, tsunamis, and whirlpools. The disasters can carry and push blocks, adding a dynamic and realistic experience to your Minecraft world.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Once the server is running, natural disasters will spawn naturally.
2. Use the `/ciao` command to greet the player.
